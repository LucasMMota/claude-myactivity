description: Show this session's MyActivity folder path
---

Report to the user the absolute path of the **current session's MyActivity folder** — the one provided by the SessionStart hook context for this session (format: `MyActivity/Work/<dd-mm-yyyy> - <Pretty Alias> - <shortid>` for day-to-day sessions, or a nested path for forks).

Print just the path (in a code span), nothing else. Do not create, rename, or list anything.
